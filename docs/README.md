# Twin Neobank — Documentation

Architecture and operations documentation for **Twin Neobank**, a non-custodial
web wallet for the ARGt stablecoin (LATAM Digital Assets Conference hackathon).

| Document | Description |
|---|---|
| [challenge.md](./challenge.md) | The hackathon spec: milestones, contract addresses, chain IDs and LayerZero EIDs. |
| [architecture.md](./architecture.md) | System overview, components, tech stack, and the M1/M2/M3 milestone-to-contract mapping, with a high-level architecture diagram. |
| [flows.md](./flows.md) | Step-by-step user and transaction flows (connect, balance, transfer, vault, bridge) with sequence diagrams. |
| [deployment.md](./deployment.md) | DigitalOcean infrastructure, Kubernetes topology, and the Terraform / GitHub Actions CI/CD pipelines. |
